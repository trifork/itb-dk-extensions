IHE XDS / Dokumentdelingsservice

DDS retrieval inside the ITB session

ITB can search, filter results and retrieve documents through the XDS service.
The user can validate a retrieved document without downloading and uploading it manually.

01

Choose identity

Select the configured signing identity. The selector shows certificate type and expiry.

02

Search DDS

Enter a test patient CPR. Filter by document type, format and optional time ranges.

03

Review results

See result counts and document details. Include or exclude repositories before choosing a document.

04

Retrieve and validate

Retrieve the selected document’s original bytes. Validate against the session’s CDA profile and release.

The retrieval report records the selected document’s metadata and original bytes. Logs include a preview.
Retrieval errors identify recognised XDS codes and the attempted repository when available.

Configured for DDS TEST1. Patient searches currently require an authorised, current employee identity (MOCES).
